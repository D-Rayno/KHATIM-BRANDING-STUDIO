# Strategic Positioning

Develop multiple plausible strategic positions before recommending one.

Score each on differentiation, attractiveness, credibility, emotional strength, visual potential, scalability, and defensibility.

Never recommend a territory only because it sounds sophisticated.

Required output: `strategy/STRATEGY-LOCK.md` with rejected alternatives and explicit reasons for rejection.
