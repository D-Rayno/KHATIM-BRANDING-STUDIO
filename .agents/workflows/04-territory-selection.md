# 04 — Territory Selection
Description: Select one creative territory and freeze the design grammar.

## Steps
1. Review all territory cards and the scorecard.
2. Ask the brand-strategist and brand-critic agents for independent assessments.
3. Select one territory.
4. Create `design/DESIGN-DIRECTION-FROZEN.md` containing concept, principles, visual grammar, prohibited conventions, and non-negotiables.
5. Move discarded territory material into `design/territories/rejected/` only if it remains useful as reference.
6. Update project control: Territory selection = COMPLETE.

## Exit criteria
All later design work can be judged against one explicit frozen direction.
