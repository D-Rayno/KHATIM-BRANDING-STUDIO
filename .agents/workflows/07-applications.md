# 07 — Applications
Description: Prove the identity in real product, enterprise, and marketing contexts.

## Steps
1. Read the visual system spec.
2. Create application tracks:
   - website/marketing
   - signing and verification UX
   - certificates and trust artifacts
   - enterprise documents
   - presentations
   - social/marketing templates
   - developer-facing assets
3. Use the application-designer agent to preserve one design system across all tracks.
4. Capture representative desktop and mobile states where relevant.
5. Ask the brand-critic to test whether the brand remains recognizable without constant logo repetition.
