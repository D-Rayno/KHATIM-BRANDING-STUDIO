# 03 — Territory Exploration
Description: Generate 5–8 distinct creative territories from the locked strategy.

## Steps
1. Read the frozen strategic direction.
2. Ask the creative-director agent to define 5–8 distinct territories.
3. For each territory produce a territory card in `design/territories/`.
4. Explore reference imagery and vector motifs only as exploratory work; do not call anything final.
5. Ask the brand-critic agent to identify generic, derivative, culturally shallow, or technically weak directions.
6. Create `design/TERRITORY-SCORECARD.md`.

## Exit criteria
At least five meaningfully different directions exist, and each has strategic plus visual rationale.
