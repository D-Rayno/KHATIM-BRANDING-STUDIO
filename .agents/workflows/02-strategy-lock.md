# 02 — Strategy Lock
Description: Convert research into an approved strategic direction before creative exploration.

## Steps
1. Read `strategy/research-index.md` and the core research findings.
2. Ask the brand-strategist agent to produce at least 4 plausible positioning territories.
3. Score them using the weighted model in `strategy/MASTER-PROMPT.md`.
4. Ask the brand-critic agent to attack the top two.
5. Select one recommended strategic direction while documenting rejected alternatives.
6. Create `strategy/STRATEGY-LOCK.md` and `strategy/STRATEGIC-DECISION-LOG.md`.
7. Update `strategy/PROJECT-CONTROL.md` to Strategy lock = COMPLETE.

## Exit criteria
The strategic idea is explicit enough that a creative director can work without guessing.
