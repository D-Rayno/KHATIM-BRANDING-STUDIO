- **Semiotic mechanism:** Displacement event; the altered state IS the proof. Passed Agent 03 outright (difference against uniform field genuinely encodes event-with-permanence).
- **Geometry:** 45° rhombic nuqta lattice; one cell displaced. Per Agent 07: base unit u, lattice pitch 2u, stroke s = u/2, gaps ≥ u. **Current SVG fails 16px as drawn (0.33px strokes) — re-construction required.**
- **Cultural logic:** Heritage as metrology — the nuqta grid IS the construction, never ornament. The only legitimate cultural-depth mode per Agent 03.
- **International behavior:** Name-agnostic (passes Nexus Trust fallback). Universal physics (pressure/impression is cross-cultural: wax, inkan, khatim).
- **Product behavior:** Passed all 10 application checks natively (Agent 05) — the only complete system. Motion: the press.
- **Differentiation:** Hardest to ape (Agent 08) — copying requires adopting the logic + grid discipline. Conditional risk: pixel/data-grid trope is live in the market leader's adjacent space; the 45°-vs-square discipline must resolve at 16px.
- **Risks:** skeuomorphism drift (mitigation: geometry-first rendering spec); pixel-grid adjacency.
- **Weaknesses:** as currently drawn, fails 16px; discipline slips turn heritage grid into generic data-texture.
- **Opportunities:** system of one verb (press); infinite upward scalability; monochrome-native.
- **Implementation complexity:** moderate — requires the rendering discipline spec (light angle, falloff, scale thresholds) before final art.
