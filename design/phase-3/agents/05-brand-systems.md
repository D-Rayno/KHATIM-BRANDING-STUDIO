# AGENT 05 — BRAND SYSTEMS DESIGNER
## Phase 3 — System-Potential Test: Can a Symbol Become a Complete Identity System?

> **STATUS: EXPLORATION ONLY.** All verdicts, rules, and rankings are STUDIES — nothing is locked. Raw material: `02-symbol-designer.md` (F-01..F-16) and `design/phase-3/svg/`, treated as unranked hypotheses. Sources: `strategy/09-SEMIOTIC-CENTER.md`, `strategy/13-DESIGN-PREPARATION.md`.
>
> **Independence note:** I selected families by my own criterion before consulting Agent 02's ranking. My question is not "is the mark good?" but "does the mechanism generate rules for every surface the brand must touch?"

---

## 1. Selection Logic + Chosen Families

**My criterion: generative capacity.** A family earns system-testing only if its semiotic mechanism is a *rule* re-executable on a certificate, a dashboard, a favicon, and a motion curve — not a *shape* pasted onto them. Secondary filters: (a) the mechanism must express state-change (asserted → attested), the brand's core verb; (b) it must respect the three-tier hierarchy without borrowing the forensic UI's clothes; (c) it must produce container logic, since documents are this brand's native habitat.

Five of sixteen families contain such a rule:

| Family | Generative rule |
|---|---|
| **F-01 Pressed Nuqta** | Uniform field + exactly one displaced cell |
| **F-02 Matrix & Impression** | Every artifact exists in two states: die (solid) / impression (void) |
| **F-05 Void Core** | Meaningful absence: the void is the payload, mass is substrate |
| **F-07 Registration Notch** | One calibrated interruption per perfect form; position = data |
| **F-15 Axis Witness** | An impartial axis that makes two parties symmetrical |

**F-01 Pressed Nuqta.** The mark *is* the 45° nuqta grid, so layout system and symbol are one object: covers bleed a 40-cell field, cards crop to 5×5, A-series margins snap to rhombic units. Icons are cell states (outline = pending, solid = attested, displaced = revoked). Motion is the press: a cell displaces, the field ripples one ring, settles permanently. Responsive reduction 7×7 → 3×3 → single pressed rhombus stays on-concept at 16px. Verification = the document's field with its pressed cell highlighted — proof you can see. The only family scoring ✅ on all twelve dimensions.

**F-02 Matrix & Impression.** The richest *behavioral* system: dual-state containers (die-face cover / impression-face content) are a genuine invention, and the signing UI is the mechanism itself — die descends, contacts, withdraws, impression remains. Held back by fixed pair compositions that don't distribute as fields, decorative-drifting patterns, responsive decay (solid-over-ring at 16px), and verification needing a third element the pair doesn't provide.

**F-05 Void Core.** Unbreakable responsive behavior (solid octagon + bright diamond hole is the best favicon on the board), a superb container idea (the void as window revealing content through the cut), and motion that narrates the deboss through absence. But the void is mute: no icon vocabulary or component grammar subdivides from it, and verification UI needs the forensic layer to speak for it.

**F-07 Registration Notch.** A superb *accent* system: flawless favicon, the notch cut in one 45° strike as motion signature, notch-position-as-data as icon invention. But one bar doesn't tile (repeats become barcode — fatal), documents aren't *built* from the mechanism, and the notch cannot carry a certificate's authority alone.

**F-15 Axis Witness.** The best *narrative* system: the axis is a spine running down pages and screens, producing ownable two-column documents mirroring Party A and Party B across the witness. Signing UI is native tripartite; the `>|<` adjacency coheres with the evidentiary brackets at product tier. Weaknesses: chevron repeats risk herringbone reading; chevrons collide with UI chrome in iconography.

## 3. System-Potential Ranking

1. **F-01 Pressed Nuqta** — grid, mark, pattern, icons, documents, UI, and motion are one mechanism. A complete system with zero borrowed parts.
2. **F-02 Matrix & Impression** — richest behavioral grammar; held from #1 by responsive decay and compositional rigidity.
3. **F-05 Void Core** — perfect container/motion/responsive behavior; system muteness in icons and verification caps it.
4. **F-15 Axis Witness** — strongest layout narrative; pattern and icon weaknesses cap it.
5. **F-07 Registration Notch** — accent system, not a leader. Highest variance confirmed.

---

## 4. Discovered System Rules (EXPLORATION)

1. **State-change is the brand's only verb.** Every behavior — mark, icon, transition, motion — expresses outline → solid (asserted → attested). No other transformation is on-brand.
2. **The nuqta grid is invisible proportion, never visible decoration.** 45° rhombic units govern margins, baselines, container ratios, icon coordinates; drawn only in structural patterns, never as ornament.
3. **Evidentiary brackets `[ ... ]` and monospace are quarantined to the product tier** (verification, audit, diffs) — never in marketing or the master mark.
4. **Solid = attested; outline = pending; displaced = revoked.** One three-state logic serving as icon vocabulary, status system, and motion language simultaneously.
5. **Motion is pressure, not movement.** Marks are pressed in, displaced, or cut — never faded, slid, or bounced. Every transition ends in a permanent state.
6. **One gesture per surface.** Any application needing more than one idea to read is off-system.

## 6. Families That Failed the System Test

- **F-03 Convergence:** the system it generates (node/convergence patterns) is every tech brand's system. Habitat: presentation slides.
- **F-04 Keystone:** static mechanism — no state-change, no generative rule; inert in UI and motion.
- **F-06 Threshold:** a UI behavior, not a brand; signature-line cliché at document scale.
- **F-08 Locked Ledger:** collapses into hamburger-icon/table reading at system scale; product-tier material.
- **F-09 Aperture:** closure exists only in motion; static system reads camera/rosette — ornament exclusion triggered.
- **F-10 Faceted Die:** needs tonal rendering to live; jewelry adjacency; brands the private key — strategically backwards.
- **F-11 Interruption:** dies below 32px; its true habitat is texture — a pattern, not a system leader.
- **F-12 Crease:** flat-first discipline kills it; the system would force skeuomorphism everywhere.
- **F-13 Misregistration:** reads as a printing defect on every surface; a trust brand cannot ship an error.
- **F-14 Split Monolith:** fracture reads *broken*, not *verified*; litigious tone; forensic-tier only.
- **F-16 Indent:** diagrammatic; the dimple vanishes at small sizes; no container or icon grammar.

---

## EXECUTIVE SUMMARY

Five of sixteen families contain a generative rule worth system-testing; eleven fail because their mechanism is static, tonal, defect-reading, or generic. **F-01 Pressed Nuqta** is the only family where grid, mark, pattern, icons, documents, UI, and motion are a single mechanism — it passes all twelve system dimensions and all ten application checks natively. **F-02** owns the signing moment, **F-05** owns responsive and motion, **F-15** owns tripartite layout, **F-07** owns the favicon — each a partial system, none complete alone. Six system rules emerged, chief among them: state-change is the brand's only verb, the nuqta grid is invisible proportion, and evidentiary brackets are quarantined to the product tier.
