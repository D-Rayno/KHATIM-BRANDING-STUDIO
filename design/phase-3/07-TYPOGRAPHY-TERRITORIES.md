## Binding rules (EXPLORATION)

1. **Dual voices, quarantined.** Forensic monospace lives ONLY in the product tier (evidentiary brackets, hash data); brand type = upright, spaced, unsentimental — no engraved-bank pastiche (Agent 01 §6).
2. **Bilingual parity.** Arabic text and Latin text share one proportion system (Agent 04 module: alif height = cap height = 5u candidate). Arabic never set smaller than Latin.
3. **Tracking discipline.** Latin caps tracked +2–6% to match Arabic's airy cadence; UI sizes must be validated (Agent 04 open question 1).
4. **No literal calligraphy.** خاتم remains a legible word; calligraphic ornament prohibited (Agent 04; Agent 03's anti-orientalism rule).

## Candidate territories (to be tested in Phase 4)

1. **Severe grotesque territory (Latin)** — neutral, upright, non-fashion width; supports institutional weight without costume. EXPLORATION.
2. **Architectural/structural numerals + caps for forensic figures** — figures in audit/certificates; tracking rules per Agent 04. EXPLORATION.
3. **Product monospace territory** — a single workhorse mono for brackets/hashes in product UI only. EXPLORATION (product-tier).
4. **Optically-matched Arabic text faces territory** — candidate families to be shortlisted in Phase 4 against the alif/cap module; EXPLORATION.

## Rejected

Rounded/friendly geometric sans (SaaS friendliness) · high-contrast fashion serifs · engraved/banknote serifs (institutional costume) · calligraphic display Arabic (ornament violation) · hacker-terminal mono at brand tier.
