# 06 — COLOR TERRITORIES (SYNTHESIS)

> **Label: EXPLORATION — NOT FINAL**
> Color TERRITORIES only. No final palette locked. Synthesized from Agents 01, 05, 06, 08 anti-pattern findings.

## Guardrails from independent agents

- **Ban glowing blue territory** (cybersecurity trope; Agent 01 §4). Cluster A/B/D competitors all converge on blue (Agent 08).
- **Ban panic red** for alarm states; tamper = alarm-by-structure in amber-oxide (Agent 06).
- **Ban neon gradients, hex-grid glow.** Weight over glow (Agent 01 §8).
- **Deboss logic drives color:** displaced geometry + physical light/shadow, not flat gradient fashion (Agent 01 §9 mitigation).

## Candidate territories (to be tested in Phase 4, not resolved here)

1. **Archival neutral territory** — paper/substrate neutrals (warm off-white to deep umber/ink), supporting the deboss' need for a light-receiving substrate. Status: EXPLORATION.
2. **Metallic-ink institutional territory** — restrained dark ink with a single metallic/foil accent usable in emboss (F-05/F-07 emboss-safe per Agent 07). Status: EXPLORATION.
3. **Oxide-alarm accent territory** — tamper/failure accent in amber-oxide reserved for product alarm-by-structure; marketing neutrals remain calm. Status: EXPLORATION (product-tier only).
4. **Monochrome-as-baseline territory** — every candidate must survive full monochrome and reverse with zero edits (F-05 does; F-01 requires re-construction). Status: REQUIREMENT, not optional.

## Rejected territories

Glowing blue · neon gradient · hacker terminal green · metallic-gold luxury (jewelry drift per Agent 01 §9) · pure black-hat dark aesthetic.
