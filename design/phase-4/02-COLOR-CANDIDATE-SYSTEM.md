# 02 — Color Candidate System

**Status: PROVISIONAL / EXPLORATION**

Phase 3 rejected glowing blue, neon green, luxury gold and black-hat dark aesthetics. The candidate direction therefore starts from archival neutrality and lets the displacement event carry meaning.

## Candidate palette A — Archival Neutral

| Role | Value | Intent |
|---|---|---|
| Ink | #111111 | primary mark / text |
| Paper | #F4F2ED | document substrate |
| Mineral | #B7B3AA | secondary structure |
| Graphite | #4A4945 | UI secondary text |
| Signal | #B36A2C | restricted product/status accent |

## Candidate palette B — Institutional Contrast

| Role | Value | Intent |
|---|---|---|
| Carbon | #151515 | authority |
| White | #FAFAF8 | clarity |
| Stone | #D9D6CF | system field |
| Slate | #62625E | supporting UI |
| Oxide | #9B4F2F | evidence/tamper state only |

## Candidate palette C — Monochrome Baseline

Pure currentColor/Canvas behavior. This is mandatory as the underlying identity proof before any chromatic direction is promoted.

## Rules

- Color must never be responsible for communicating trust or security.
- The primary mark must survive without color.
- The accent is informational/product behavior, not logo decoration.
- No gradient is required to create depth.
- No metallic effect is required to create authority.

**No palette is final until the name and business gates clear.**
