# 03 — Typography Candidate System

**Status: PROVISIONAL / EXPLORATION**

The identity needs a bilingual system that feels contemporary and exact without becoming cyberpunk, legalistic, or ornamental.

## Direction

### Brand voice
A severe, contemporary grotesque / neo-grotesque family with strong numerals, controlled terminals and enough Arabic support for true bilingual parity.

### Product voice
A restrained monospace may appear only for evidence, hashes, IDs, timestamps and audit data. It must never become the brand's dominant personality.

### Arabic
Arabic should be structurally matched to the Latin system rather than treated as decorative calligraphy. Test modern Arabic sans families with stable numerals and clean punctuation.

## Hierarchy candidate

1. Display / identity: bold contemporary sans
2. Text: neutral readable sans
3. Evidence: restrained monospace
4. Arabic: optical match to the Latin hierarchy

## Tests required

- Latin/Arabic lockup at 48px, 32px and 20px
- Arabic baseline and cap-height perception
- Latin tracking range
- bilingual navigation
- certificate heading
- product table
- mobile UI

## Explicitly rejected

- calligraphic display Arabic
- engraved bank typography
- rounded friendly startup typography
- futuristic techno fonts
- excessive monospace branding

**No typeface is final in Phase 4.**
