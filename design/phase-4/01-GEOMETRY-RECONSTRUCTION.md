# 01 — Geometry Reconstruction

## Current status

**Development candidate — not final.**

Phase 3 correctly identified the original Finalist A as a promising system but noted that the drawn geometry fails the 16px proof and that its defensibility is primarily system-level. fileciteturn20file0L2-L2

## Reconstruction principle

Do not mechanically preserve the Phase 3 drawing. Reconstruct the identity from its underlying idea:

> **A uniform field becomes meaningful when one unit is permanently changed.**

The visual system therefore has four layers:

1. substrate / field
2. repeated module
3. decisive state change
4. responsive reduction

## Responsive rule

| Size | Required behavior |
|---:|---|
| 256px+ | full construction may reveal field logic |
| 128px | field remains legible, event dominant |
| 64px | reduce secondary lattice detail |
| 48px | preserve decisive silhouette |
| 32px | compact construction permitted |
| 24px | compact construction preferred |
| 16px | insurance form only |

These are development thresholds, not final brand rules.

## QA questions

- Is the altered unit visible immediately?
- Does the mark still work in one color?
- Does it look like generic pixel art?
- Does it become a generic seal when enclosed?
- Does it survive at 16px without accidental artifacts?
- Can the system be recognized without explaining the Arabic reference?
- Does the negative construction remain a derivative rather than competing with the primary idea?

## Decision

**Do not lock A yet.** Continue comparative visual testing between A, B and C. The 16px derivative is an operational solution, not evidence that the master mark has succeeded at 16px.
