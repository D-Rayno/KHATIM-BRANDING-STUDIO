# Visual Clichés

Avoid as primary brand assets:

- literal shield
- padlock
- keyhole
- checkmark inside circle/shield
- generic digital signature scribble
- stock handshake
- hooded hacker
- binary code rain
- glowing circuit board
- generic hex-grid
- anonymous “secure globe”
- dark-blue gradient by default

These can be used only if reinterpreted in a highly ownable system.
