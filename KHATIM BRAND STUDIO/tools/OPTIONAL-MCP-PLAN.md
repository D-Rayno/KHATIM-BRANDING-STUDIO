# Optional external integrations

Antigravity can use skills and MCP servers to extend agent capabilities. Keep this project functional without external integrations first.

Recommended integration order, only when materially useful:

1. Browser/web research — official/current sources.
2. Figma — if a connector/MCP is available in your environment and you want an editable canvas as the system of record.
3. Vector generation/editing service — if available through a stable API/MCP.
4. Image generation — for art direction and photography exploration.

Do not add credentials to this repository. Put secrets in Antigravity's supported project/global configuration.

The project itself remains usable with native file/web tools and manual import/export.
