# 05 — Logo System
Description: Develop the production-grade Khatim mark and bilingual identity architecture.

## Steps
1. Confirm `design/DESIGN-DIRECTION-FROZEN.md` exists.
2. Ask the logo-designer to generate multiple concepts within the frozen grammar.
3. Evaluate each concept for differentiation, memorability, Arabic-Latin harmony, scalability, and technical cleanliness.
4. Ask the brand-critic to attack the top candidates.
5. Select a primary candidate and document the decision in `design/logo/LOGO-DECISION.md`.
6. Build the required variants as editable SVG.
7. Run a technical SVG check.
8. Do not release a final logo until the critic gate is passed.
