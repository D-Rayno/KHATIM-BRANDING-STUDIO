# 06 — Brand System
Description: Turn the frozen logo into a complete visual grammar.

## Steps
1. Read the final logo decision and frozen creative direction.
2. Build color behavior, typography, grid, iconography, patterns, illustration, imagery, motion, and UI rules.
3. Parallelize independent asset families after their governing rules are defined.
4. Create `design/system/VISUAL-SYSTEM-SPEC.md`.
5. Populate `assets/ASSET-MANIFEST.csv`.
6. Run brand critique before approving the system.

## Exit criteria
The system feels generated from one idea rather than assembled from unrelated assets.
