# 01 — Research Ingest
Description: Load, index, verify, and structure all Khatim strategic evidence before design begins.

## Steps
1. Read `strategy/MASTER-PROMPT.md` and `strategy/PROJECT-CONTROL.md`.
2. Read the supplied research archive and any extracted research files in `research/`.
3. Use the research-analyst agent to identify the strongest evidence, conflicts, missing information, and current facts requiring web verification.
4. Create `strategy/research-index.md`.
5. Create `strategy/research-gates.md` listing strategic questions still unresolved.
6. Update project status: Research ingestion = COMPLETE; Strategy lock = READY.
7. Do not create final visual identity assets.

## Exit criteria
A decision-maker can see what is known, what is inferred, and what remains unresolved.
