# Creative Territories

Develop 5–8 clearly differentiated territories.

Each must contain:
1. Name
2. Core idea
3. Why now
4. Strategic rationale
5. Emotional outcome
6. Symbolic vocabulary
7. Shape vocabulary
8. Logo opportunity
9. Typography behavior
10. Color territory
11. Imagery
12. Motion
13. UI implications
14. Strengths
15. Risks
16. Competitor overlap
17. Differentiation potential

Do not create final logo artwork here.
