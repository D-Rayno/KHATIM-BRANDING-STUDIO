# Brand QA

Use two layers:
1. creative/strategic QA
2. technical/production QA

Block release when a critical issue is found in differentiation, meaning, Arabic/Latin integrity, system consistency, or asset validity.

Always produce a `qa/` report and update status in `strategy/PROJECT-CONTROL.md`.
