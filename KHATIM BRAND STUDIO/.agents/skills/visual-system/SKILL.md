# Visual System

Start from the frozen identity grammar.

Create rules first, then assets.

Required outputs may include:
- color behavior and tokens
- type hierarchy
- Arabic/Latin pairing rules
- spacing and grid
- icon rules
- pattern grammar
- illustration grammar
- imagery direction
- motion principles
- UI components

Never solve each surface independently.
