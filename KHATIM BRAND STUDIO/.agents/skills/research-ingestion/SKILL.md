# Research Ingestion

## Use when
- starting the project
- refreshing research
- verifying whether a strategic statement is evidence-backed

## Process
1. Inventory files in `research/`.
2. Unpack supplied archives when appropriate.
3. Read executive summary, competitive intelligence, naming research, semiotics, visual strategy, verbal strategy, strategic analysis, and designer handoff.
4. Build a `strategy/research-index.md` with major findings and evidence tags.
5. Record unresolved contradictions.
6. Update `strategy/PROJECT-CONTROL.md`.

## Exit criteria
The project has a readable evidence index and a clear list of unresolved gates.
