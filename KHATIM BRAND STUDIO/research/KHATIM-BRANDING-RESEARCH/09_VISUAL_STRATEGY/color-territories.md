# Color Territories

## Territory A — Institutional depth
Ink / slate / warm neutral / restrained accent.

## Territory B — Mineral trust
Stone / deep green / muted metallic accent.

## Territory C — Contemporary authority
Deep indigo / warm off-white / distinctive signal color.

## Territory D — Heritage re-coded
Earth / parchment-inspired neutral / controlled jewel accent.

## Territory E — Light trust
Bright base / dark text / saturated but disciplined signal color.

Do not default to corporate blue simply because the category does.
