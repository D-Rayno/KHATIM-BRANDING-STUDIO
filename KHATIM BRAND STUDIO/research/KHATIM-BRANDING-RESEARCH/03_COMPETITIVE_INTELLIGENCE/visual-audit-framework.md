# Competitive Visual Audit Framework

A professional designer should run a second, screenshot-based visual audit before final route selection.

## Capture for each competitor
- homepage hero
- logo lockup
- navigation
- product screenshots
- sign flow
- compliance/trust page
- footer
- illustration system
- typography samples
- primary and secondary colors

## Code each element
1. Color
2. Shape
3. Symbol
4. Type personality
5. Image style
6. Motion
7. Trust signal
8. Voice

The objective is to visualize category sameness before selecting Khatim’s identity direction.
