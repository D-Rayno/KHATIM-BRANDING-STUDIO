# KHATIM BRAND STUDIO — ANTIGRAVITY

A production-oriented Google Antigravity project blueprint for turning the Khatim brand research package into a complete, coherent identity system with vector-first assets.

## Operating model

Antigravity is the orchestration layer. The project uses custom agents for specialization, skills for reusable methods, rules for persistent constraints, and workflows for repeatable production sequences.

The structure follows current Antigravity conventions:
- Workspace custom agents: `.agents/agents/<name>/agent.md`
- Workspace skills: `.agents/skills/<skill>/SKILL.md`
- Workspace rules: `.agents/rules/`
- Workflows: Markdown workflows invoked as `/workflow-name`

The project intentionally separates strategy, creative direction, logo development, system design, applications, criticism, and production QA.

## Start here

1. Put the complete Khatim research package under `research/`. The supplied `Khatim-Branding-Research.zip` is copied here as the starting input.
2. Open this folder as the Antigravity project.
3. Read `strategy/PROJECT-CONTROL.md` after running `/01-research-ingest`.
4. Run workflows in order:
   - `/01-research-ingest`
   - `/02-strategy-lock`
   - `/03-territory-exploration`
   - `/04-territory-selection`
   - `/05-logo-system`
   - `/06-brand-system`
   - `/07-applications`
   - `/08-guidelines`
   - `/09-final-qa`
5. Do not skip the critic gates.

## Non-negotiable strategic gate

The earlier research package identified a serious naming collision involving an existing Khatim offering in the trust/signature/PKI space. Treat this as an unresolved strategic/legal dependency. Identity exploration may continue, but no recommendation should imply that naming clearance has been established.

## Asset philosophy

Vector-first. Prefer editable SVG for marks, icons, patterns, diagrams, seals, and graphic elements. Raster imagery is allowed for photography or texture, but should not be used as the master source for marks.

## What this project deliberately does not freeze

It does not hard-code a final logo, exact color palette, exact fonts, or one visual territory before research and competitive challenge are complete.
